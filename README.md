# About
**PNGTuber Live** is a Python application for streamers that makes setting up a stream avatar quick and easy.
> Currently available for **Windows** only.

# Download
Go to the **[Releases page](https://github.com/KaDeroxFR/PNGTuber-Live/releases/latest)** and download the latest installer.

# Usage
1. Run the application and configure it however you like.
2. Click **Save** to store your settings. They will be loaded automatically every time you open the app.

## Adding your PNGTuber to OBS (or another recording app)
1. Add a **Browser Source** to your scene.
2. Enter the following address as the URL:
```url
http://localhost:<port>
```
Replace `<port>` with the port number shown in the app.
